# Собственная почта в RegMyAss

## Gmail: автоматическое чтение писем

Разработчик один раз добавляет Google OAuth Client ID при сборке. После этого пользователь выбирает Gmail в настройках расширения и нажимает «Войти через Google». Пароль расширению не передаётся.

1. В `chrome://extensions` скопируйте ID установленного RegMyAss.
2. В [Google Cloud Console](https://console.cloud.google.com/) включите Gmail API и настройте экран согласия OAuth. Для личной проверки добавьте свой Gmail как тестового пользователя. Нужное разрешение: `https://www.googleapis.com/auth/gmail.readonly`.
3. Создайте OAuth Client ID типа **Chrome Extension** с ID расширения из шага 1.
4. В `oauth-clients.local.json` укажите только выданный публичный `googleClientId`. Не копируйте туда client secret.
5. Выполните `npm run build`, обновите расширение в `chrome://extensions` и нажмите «Войти через Google» в настройках RegMyAss.

Файл `oauth-clients.local.json` исключён из Git. Вместо него можно передать `REGMYASS_GOOGLE_CLIENT_ID` как переменную окружения при сборке.

Google относит разрешение `gmail.readonly` к restricted scopes. Для приложения, доступного другим людям, может потребоваться проверка Google.

## Proton Mail: ручное подтверждение

В настройках выберите Proton Mail и укажите адрес. Расширение подставит его в регистрационную форму. Когда сайт отправит письмо, нажмите «Открыть Proton Mail», войдите на сайте Proton и скопируйте код в окно расширения либо перейдите по ссылке из письма. После этого завершите регистрацию в окне расширения.

Автоматическое чтение Proton Mail через OAuth в расширении не поддерживается. Proton предоставляет доступ сторонним почтовым клиентам через локальный Proton Mail Bridge; он доступен с платным планом и не подключается напрямую к браузерному расширению.
